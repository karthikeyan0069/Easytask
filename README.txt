EASYTASK OFFICIAL WEBSITE — HTML / CSS / JAVASCRIPT

Files:
- index.html
- style.css
- script.js

Run locally:
1. Extract the ZIP.
2. Open index.html in a browser, or use VS Code Live Server.

Deploy to Vercel:
1. Create a GitHub repository and upload these three files.
2. Import the repository in Vercel.
3. Framework preset: Other.
4. Build command: leave blank.
5. Output directory: . (root).
6. Deploy.

Before launch:
- Replace the illustrative dashboard/phone preview with real EasyTask screenshots if desired.
- Add the final APK URL in the download section.
- Google Form feedback link is already connected:
  https://forms.gle/wNiLXLTucVuzdSyk7

This is a static website. No backend or database is required.
